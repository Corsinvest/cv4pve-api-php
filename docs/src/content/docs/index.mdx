## Why

An application that manages Proxmox VE (a customer portal, a scheduled job, a monitoring or billing
tool) has to speak its REST API: tickets and tokens, paths, parameters, JSON, tasks that end later.
Written by hand it is a layer of HTTP code to build and to keep up with every Proxmox VE release.

cv4pve-api-php is that layer, generated from the API itself. The calls follow the tree of the API,
so the [Proxmox VE API viewer](https://pve.proxmox.com/pve-docs/api-viewer/) is also the reference of
the client, and the comment of each method carries the same descriptions.

```php
use Corsinvest\ProxmoxVE\Api\PveClient;

$client = new PveClient('pve01', 8006);
$client->setApiToken('automation@pve!app=aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee');

// GET /nodes/{node}/qemu/{vmid}/status/current
$result = $client->getNodes()->get('pve01')->getQemu()->get(100)->getStatus()->getCurrent()->vmStatus();

echo $result->isSuccessStatusCode()
    ? "VM {$result->getResponse()->data->vmid} is {$result->getResponse()->data->status}\n"
    : "{$result->getStatusCode()} {$result->getReasonPhrase()}\n";
```

## In your application, API only

The client runs where PHP runs (a web application, a command line script, a scheduled job, a
container) and talks only to the Proxmox VE REST API on port 8006. Nothing is installed on the nodes
and no SSH is needed. What an application can do is what its API token or user is allowed to do: give
it a token with just the privileges it needs, see [Permissions](/cv4pve-api-php/permissions/).

## Where it fits

The cv4pve suite follows the Unix philosophy: each tool does one thing and does it well. This library
is the PHP way into the same API the tools of the suite use. If a ready tool already does the job,
use the tool: [cv4pve-cli](https://corsinvest.github.io/cv4pve-cli/) calls the API from any shell,
[cv4pve-autosnap](https://corsinvest.github.io/cv4pve-autosnap/) takes snapshots with retention. The
same client exists for .NET with [cv4pve-api-dotnet](https://corsinvest.github.io/cv4pve-api-dotnet/),
for Java with [cv4pve-api-java](https://corsinvest.github.io/cv4pve-api-java/) and for PowerShell
with [cv4pve-api-powershell](https://corsinvest.github.io/cv4pve-api-powershell/).
